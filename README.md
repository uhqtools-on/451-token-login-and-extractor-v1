# TUTO
Télécharger tout les fichiers les mettres dans un seul et unique fichier. 
Se rendre sur google chrome, l'icone de puzzle en haut à droite, gérer les extensions, charger l'extension non empaquetée, sélectionner le dossier avec tout les fichiers dedans.
Clique sur l'icone grise *4*
